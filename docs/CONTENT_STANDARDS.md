# Tajkart content standards

## Originality

Create explanations, examples, exercises, diagrams, and learning plans specifically for Tajkart. Topic names and general concepts may be shared across the industry; distinctive text, structure, illustrations, and code from another work must not be copied without permission and correct licensing.

## Minimum guide structure

1. Title and intended audience
2. Learning objectives
3. Prerequisites
4. Explanation in original words
5. A worked example or practical activity
6. Common mistakes and safety considerations
7. Practice questions
8. Further reading, if verified and appropriate
9. Last-reviewed date for information likely to change

## Accuracy

Test code where practical. Distinguish established facts from recommendations. Mark version-specific guidance. Review job, scholarship, and offer information before presenting it as current.

## Accessibility and inclusion

Use meaningful headings, descriptive link text, alt text for images, readable tables, and plain language. Avoid assumptions about a learner's device, budget, location, or prior education.
