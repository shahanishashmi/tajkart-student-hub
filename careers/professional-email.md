A useful professional email makes it easy for the reader to understand who you are, why you are writing, and what response you need. Keep the message brief and courteous; do not add personal details that are not necessary.

## Use a simple structure

1. **Subject:** name the topic and, if needed, the date or role.
2. **Greeting:** use the person's name when you know it; otherwise choose a neutral greeting.
3. **Context:** introduce yourself and refer to the application, class, or earlier message.
4. **Request:** ask one concrete question or state the action you completed.
5. **Close:** thank the reader and use your name.

Example structure:

```text
Subject: Question about the application project format

Hello,

I am preparing an application for the programme listed on your official site. Could you clarify whether the project link should be included in the form or attached separately?

Thank you,
[Your name]
```

This is a writing example, not a real programme contact or application instruction.

## Check before sending

- Confirm the recipient and reply address.
- Make sure each attachment is the correct file and does not expose private information.
- Use a descriptive file name and remove unnecessary metadata from documents.
- Read the message once for spelling, tone, and the exact request.
- If following up, refer to the previous message and allow a reasonable response period.

## Practice

Write a message asking a teacher for feedback on one portfolio project. Keep it under six sentences, include a link only if it is safe to share, and ask for one specific kind of feedback.
