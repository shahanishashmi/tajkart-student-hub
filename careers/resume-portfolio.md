## Learning objectives

By the end, you can choose relevant evidence for an application, describe a project clearly, and check a resume for accuracy and readability.

## Before you draft

Collect the role description, the skills it asks for, and examples that show what you have practised. A course completion alone may say little about what you can do; pair it with a small project, exercise, or contribution you can explain.

## Write useful project evidence

Describe the problem, your action, and the result. Keep the statement specific and truthful. For example:

**Too vague:** “Made a Python project.”

**Clearer:** “Built a Python study-session tracker that totals minutes from a list and reports the weekly sum.”

Only add numbers, users, performance results, or team impact if you measured them and can explain how. State your own role accurately when a project involved other people.

## Make the resume easy to scan

- Put your name and a professional contact method at the top.
- Order sections around the role: relevant projects, skills, education, and experience as appropriate.
- Use short bullets that begin with clear actions.
- Name tools in context; a skills list should be supported by examples elsewhere.
- Keep dates, titles, links, and spelling consistent.
- Use a simple layout with readable contrast and headings; do not rely only on color or graphics to convey meaning.
- Remove sensitive personal details an application does not require.

## Build a useful portfolio page

For each project, provide its purpose, screenshots or a short demo where suitable, setup steps, a sample input/output, what you learned, and known limitations. Link to source code only when you have the right to share it. Never publish API keys, private data, or someone else's work without permission.

## Final review

Compare the resume with the role and move the most relevant evidence higher. Ask a trusted reader to check whether each sentence is clear. Open every link and test the project setup using the written instructions. Remove any statement you cannot comfortably support in a conversation.
