An internship application is a chance to show what you have learned and how you approach unfamiliar work. You do not need to claim expert status. A clear project, honest skill description, and thoughtful questions are stronger than unsupported claims.

## Check the opportunity first

Find the programme on the organisation's official website. Compare the title, dates, eligibility, location or remote terms, application process, and any fees with the announcement you received. Treat a request for payment to guarantee placement, account passwords, or urgent personal documents as a warning. Ask a school adviser or trusted adult if a request is unclear.

## Make a requirement-to-evidence table

For each requirement, write one example from a lesson, project, class, volunteer activity, or team task. Mark the difference between “used once,” “practised independently,” and “used in a reviewed project.” If you have not tried a tool, say so and name the related skill you are learning.

| Requirement | Evidence I can explain | What I still need to learn |
|---|---|---|
| Basic programming | A small function with tests for normal and edge inputs | Organizing a larger codebase |
| Team communication | A clear issue report or shared class project | Reviewing a teammate's code |

These examples show how to structure your own evidence; they are not claims about a particular employer or position.

## Prepare the application

1. Tailor the order of your resume to the role without changing the facts.
2. Link to a portfolio project with a short README, setup steps, and known limits.
3. Review the application instructions and submit only information they request.
4. Keep a copy of the role description and the date you applied.
5. Prepare two specific questions about supervision, learning goals, or the work itself.

## Practice and next steps

Explain one project in two minutes: its goal, your contribution, one challenge, how you tested it, and what you would improve.
