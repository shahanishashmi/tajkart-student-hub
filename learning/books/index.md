This guide teaches a reusable way to get value from technical reading. It does not reproduce or recommend a particular book.

## Before reading

Set one question you hope the chapter will answer. Skim the headings and examples, then estimate how much time you can give it. A chapter is easier to use when it has a specific purpose.

## While reading

Pause at an unfamiliar idea and write a short explanation in your own words. Run code examples yourself where possible. Change one input and predict how the result will differ. Mark questions to revisit instead of copying long passages into notes.

## After reading

Close the book and summarise the main idea from memory. Make one small example or solve a related problem without looking. Return to difficult sections with a concrete question. Record the title, edition, and page reference for notes you may need to cite.

## Choose material responsibly

Use a library, publisher, author, or other lawful source. Confirm that a resource matches your experience level and goals. This site does not provide pirated copies or host third-party book content.
