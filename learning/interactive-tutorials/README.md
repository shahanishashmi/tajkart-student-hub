# Interactive Tutorials

An interactive tutorial should let learners make a decision, see a result, and understand why that result occurred.

## Design pattern

- State one learning objective.
- Introduce the smallest useful concept.
- Ask the learner to predict an output or behaviour.
- Provide a runnable or simulated activity.
- Explain the result and common misconceptions.
- Offer a hint before revealing a solution.
- End with a variation that checks transfer, not memorisation.

## First tutorial ideas
- Trace a variable through a short program
- Practise conditionals with everyday rules
- Visualise a loop step by step
- Debug a deliberately flawed function
- Explore HTTP request and response structure
