A playground is any isolated place to test an idea. A local folder with one small program can be enough.

## Keep experiments manageable

- Make a new folder or copy before experimenting with an unfamiliar tool.
- Change one thing at a time, then compare the result.
- Use sample data rather than passwords, personal records, or private work.
- Save useful experiments with a short note describing what you learned.
- If installing packages, check the package name and source before trusting it.

For a first experiment, run the snippets in the [variables lesson]({{ '/learning/lessons/python-variables/' | relative_url }}) and change one value at a time. This repository does not run submitted code on a server; learners choose their own local or third-party environment.
