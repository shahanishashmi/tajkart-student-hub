# Coding Playgrounds

A playground is a controlled space for experiments. Tajkart guides should explain what can be changed, what output to observe, and how to reset the exercise.

## Safe experimentation checklist

- Use a local or sandbox environment for unfamiliar code.
- Never paste secrets, tokens, personal data, or company data into public tools.
- Avoid running commands whose effects you do not understand.
- Save a known-good starting point before experiments.
- Change one variable at a time and record the result.
- Prefer read-only examples when exploring production infrastructure.

## Planned playgrounds
Variables and types, functions, data structures, SQL queries using sample data, HTTP requests, Git branching, and basic algorithm visualisation.
