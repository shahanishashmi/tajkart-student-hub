# Tajkart Learning Library

The Learning Library is designed around formats and learning outcomes rather than copied directories of external links.

## Content formats

| Area | Purpose |
|---|---|
| Books and reading guides | Learn to select, read, and apply technical material |
| Courses and study plans | Follow structured self-study curricula |
| Podcasts and screencasts | Learn actively from audio and video |
| Interactive tutorials | Learn concepts through guided practice |
| Playgrounds | Experiment in safe, reversible environments |
| Cheatsheets | Review concepts with concise original references |
| Problem sets | Build fluency through original exercises |
| Subjects | Navigate computer-science and software topics |
| Languages | Plan multilingual learning resources |

Each section starts with original guidance and templates. Specific learning material will be added as it is authored and reviewed.
