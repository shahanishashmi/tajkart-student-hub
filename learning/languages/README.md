# Programming and Human-Language Coverage

The reference archive covered learning materials in many human languages and across many programming languages. Tajkart will preserve that breadth as a planning goal, without copying its entries.

The [published paths](index.md) currently cover C, C++, Java, Python, JavaScript/TypeScript, HTML/CSS, SQL, PHP, Go, Rust, and shell scripting. These are introductory learning paths, not complete language courses. The [locale inventory](../../data/language_coverage.yml) records the 57 source locale codes and Tajkart's actual language content status.

## Programming-language families to cover

- **General-purpose:** C, C++, C#, Java, Kotlin, Go, Rust, Swift
- **Web:** JavaScript, TypeScript, HTML, CSS, PHP
- **Scripting and automation:** Python, Ruby, Bash, PowerShell, Perl
- **Data and query:** SQL, R, Julia
- **Functional and academic:** Haskell, Scala, Clojure, Elixir, Erlang, F#
- **Mobile and game development:** Dart, Lua, GDScript, Objective-C
- **Systems and specialised:** Assembly, Verilog, VHDL, Solidity

## Human-language publishing plan

Plan translations based on learner demand and reviewer availability, including English, Hindi, Urdu, Arabic, Bengali, Spanish, French, German, Portuguese, Japanese, Korean, Chinese, and other languages requested by the community.

Translations should be written or reviewed by fluent contributors, keep technical terms consistent, and link back to the canonical guide. Do not label machine-generated or unreviewed translations as professionally verified.
