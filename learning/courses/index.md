This is an estimate of about ten hours across four weeks, not a credential, deadline, or accredited course. A session may take 25–45 minutes; change the pace to fit your schedule. Choose one language and keep a short learning log: What did I try? What surprised me? What will I try next?

## Prerequisites and materials

No prior programming experience is required. You need a text editor and a way to run short programs. The examples link to Python lessons; you may translate the exercises into another language after you understand the expected behavior.

## Modules and assignments

| Week | Module and objectives | Practical assignment |
|---|---|---|
| 1. Values and decisions | Name values, distinguish text and numbers, use input/output and a condition. | Build a unit converter or calculate a simple total. Complete [variables and values]({{ '/learning/lessons/python-variables/' | relative_url }}). |
| 2. Repetition and functions | Trace a loop, use an accumulator, give a function inputs and a return value. | Summarize several session durations. Complete [loops]({{ '/learning/lessons/problem-solving-loops/' | relative_url }}) and [functions]({{ '/learning/lessons/python-functions/' | relative_url }}). |
| 3. Collections and problem solving | Store ordered values, look up a value by key, describe an algorithm. | Count completed tasks and find the largest value. Review the [collections lesson]({{ '/learning/lessons/python-lists-dictionaries/' | relative_url }}). |
| 4. Build and review | Organize a small program, test its behavior, and save focused changes. | Finish a reading tracker or flashcard quiz and use [small Git commits]({{ '/learning/lessons/git-small-commits/' | relative_url }}). |

## Knowledge checks

After each module, explain one example without reading it. Predict output before running the code. Try an empty input, a typical input, and a boundary input. If the output surprises you, describe the first point where your prediction and the program differ.

## Final project and assessment rubric

Choose a reading tracker, study-session total, or flashcard quiz. It should have a clear input and output, named functions, at least one collection, and tests for an ordinary case and an edge case. Self-score 0–2 for correct behavior, readable structure, useful tests, and explanation. A zero means revise that area; the score is formative, not an official grade.

## Completion criteria and next steps

You can explain the project, change one behavior without losing track of its effect, and show test results. Then choose the [data structures course]({{ '/learning/courses/data-structures/' | relative_url }}) or [web foundations course]({{ '/learning/courses/web-development/' | relative_url }}), and use the [subject map]({{ '/learning/subjects/' | relative_url }}) to choose what to study next.
