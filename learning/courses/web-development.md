Budget roughly 25 hours across six weeks; the estimate varies with your starting point and tools. Use local files or a static host. This course does not require a framework, account system, or collection of visitor data.

## Prerequisites

Know how to create and edit a text file. Basic programming experience helps, but the course introduces JavaScript concepts as needed. Read the [web-development guide]({{ '/learning/guides/web-development/' | relative_url }}).

## Modules

| Week | Focus | Assignment |
|---|---|---|
| 1 | HTML document, headings, links, lists, landmarks | Make a three-section page and check heading order. |
| 2 | Forms, labels, input types, validation messages | Build a local study-plan form; do not collect personal records. |
| 3 | CSS box model, typography, layout, responsive rules | Support a narrow viewport and 200% zoom without clipping. |
| 4 | JavaScript values, functions, events, and DOM | Add a filter with an empty state and announced result count. |
| 5 | URLs, requests, browser devtools, and page performance | Inspect local assets and explain one network request. |
| 6 | Accessibility review and project polish | Submit a small reference page with keyboard and content checks. |

## Knowledge checks and project

At each stage, identify which part belongs in HTML, CSS, or JavaScript. The final project is a searchable personal learning log using sample data. Include descriptive links, labeled controls, visible focus, meaningful alternatives for images, and a no-results message.

## Assessment rubric

Score 0–2 for semantic structure; responsive reflow; keyboard access and focus; clear interaction feedback; and reproducible checks. Any 0 means revise before calling the project complete. Passing this self-review is not a formal accessibility certification.

## Completion and next steps

The page should work without a mouse, remain readable when enlarged, and handle empty and typical data. Record any untested screen reader or browser behavior.
