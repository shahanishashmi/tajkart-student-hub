# Courses and Study Plans

This section provides Tajkart-authored curricula and study schedules. It is not a mirror of another site's course catalogue.

The [course index](index.md) now includes three plans: programming foundations, data structures, and web foundations. Time estimates are planning aids, not accreditation or guaranteed outcomes.

## A practical four-week starter plan

### Week 1 — Foundations
Set up a development environment, learn variables and basic data types, and practise input/output. Finish with a small command-line program.

### Week 2 — Control flow and functions
Practise conditions, loops, functions, and decomposition. Build a number guessing game or unit converter.

### Week 3 — Collections and debugging
Work with arrays/lists, maps/dictionaries, errors, and basic testing. Build a simple record tracker.

### Week 4 — A small project
Choose a real problem, write requirements, implement a minimal solution, document setup, and ask another person to review it.

## How every Tajkart course should work
Each course should define its audience, prerequisites, outcomes, lesson sequence, exercises, checkpoints, a capstone, and a completion rubric. Study time estimates are guidance, not guarantees.
