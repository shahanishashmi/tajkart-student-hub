# Problem Sets and Project Challenges

Practice problems should develop reasoning, not just memorisation. Tajkart-authored challenges will include difficulty, prerequisites, constraints, sample input/output, hints, and an explanation of at least one solution approach.

## Difficulty levels
- **Starter:** one concept, small input, direct feedback.
- **Developing:** combine two or three concepts and handle edge cases.
- **Applied:** solve a realistic task with requirements and tests.
- **Portfolio:** document trade-offs, tests, setup, and limitations.

## Original starter challenges
1. Convert a temperature between units and validate input.
2. Count word frequency in a paragraph.
3. Build a simple expense summary from sample records.
4. Validate a password policy without storing the password.
5. Model a library checkout using in-memory sample data.
6. Parse a small CSV file and report invalid rows.

Do not submit copyrighted contest statements or proprietary interview questions. Create original problem statements and test cases.
