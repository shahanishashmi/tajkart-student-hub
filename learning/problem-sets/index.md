For each problem, write the expected result before coding. Reference solutions are included after the hint. The Python functions are also imported by the local unit tests; the SQL example is executed against a temporary SQLite database. Difficulty describes the concept, not the time required for every learner.

## Choose a practice format

- Start with the [interactive prediction routine]({{ '/learning/interactive-tutorials/' | relative_url }}) to read, predict, run, and explain a short example.
- Try the [four-question code-reading quiz]({{ '/learning/interactive-tutorials/quiz/' | relative_url }}) for immediate browser-side feedback.
- Choose a problem below when you are ready to write a solution, test an edge case, and compare your reasoning with a reference answer.

For a guided sequence from first study goal through practice and a project, see [Start with a student learning goal]({{ '/getting-started/' | relative_url }}).
