# Tajkart Cheatsheets

Cheatsheets are concise revision aids, not substitutes for understanding. Tajkart cheatsheets should be written from scratch, versioned when tools change, and paired with a worked example.

## Planned original quick references
- Git essentials and safe collaboration
- HTML semantic elements
- CSS layout concepts
- JavaScript fundamentals
- SQL query building
- HTTP status and request concepts
- Linux command-line safety
- Testing and debugging checklist

Each cheatsheet should identify the audience, scope, version assumptions, and last review date. Commands that can delete or modify data must be clearly marked.
